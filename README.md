# QuickTasks

A clean, modern To-Do List application built with React, TypeScript, and Tailwind CSS, migrated from the original Flutter app.

## Features

- **Add Tasks**: Quickly create tasks with real-time validation and automatic focus management.
- **Task Management**: Check off tasks as completed or remove them with a single click.
- **Live Summary**: Real-time counters showing pending and completed tasks.
- **Material-Inspired Design**: Clean typography, card layouts, and responsive design for mobile and desktop.
- **Theme Support**: Seamless toggle between light mode and dark mode with persistence.
- **Local Persistence**: State automatically persists in `localStorage` across page reloads.

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
